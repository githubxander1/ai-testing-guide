这里沉淀经过实际项目验证、以后还能复用的测试经验。按主题归档，避免把项目用例、操作手册和经验结论混成一堆；每篇尽量写清适用条件和验证依据。

## 经验记录模板

每篇记录建议回答：适用产品和环境是什么；问题或目标是什么；如何复现和验证；发现了什么；哪些规则可以复用；有哪些例外或尚未确认的部分。

## 资料整理方式

原始资料按类别收录在[资料库下载索引](library/)中；整理后的方法和经验另写成主题文章，便于阅读与复用。
