## 经验记录模板

每篇记录建议回答：适用产品和环境是什么；问题或目标是什么；如何复现和验证；发现了什么；哪些规则可以复用；有哪些例外或尚未确认的部分。

## 资料整理方式

`D:\Xander\Download\测试` 中有用例、规范、性能和工具等多类资料，可按上表逐步提炼成经验文章。原始文件继续留在本地；发布到本站前先去掉客户、账号、内部地址、个人信息和未获授权的项目内容。本站是公开的 GitHub Pages，只有适合公开的整理稿才放进 `docs/personal-experience/`。
