# Python 基础练习 第一组

以下练习根据常见 Python 基础主题重新设计，适合边写代码边补测试；不含原题库的逐题复制。每题都要说明输入范围，并覆盖空值、重复值或边界情况。

## 字符串与集合

1. **规范化标签**：输入一组字符串，去掉首尾空白、忽略空字符串，并将保留值按首次出现顺序去重。测试大小写是否视为相同，由你先定义规则。
2. **词频统计**：统计一段文本中每个单词出现次数；标点作为分隔符，大小写不敏感。覆盖空文本和重复空格。
3. **手机号脱敏**：将符合约定长度的号码中间位替换为星号；非法长度应返回清楚的错误结果，不要悄悄截断。
4. **括号校验**：判断由 `()[]{}` 组成的字符串是否配对。覆盖空串、单个左括号、交错闭合和嵌套情况。

## 列表、字典与循环

5. **订单汇总**：输入订单列表，按用户统计有效订单金额；取消订单不计入，金额为零和金额缺失要分别处理。
6. **按键分组**：输入包含姓名和部门的记录，生成“部门到姓名列表”的映射；保留原始相对顺序。
7. **数据质量检查**：扫描用户记录，返回缺少必填字段的行号和字段名；不在结果中暴露完整个人数据。
8. **分页生成**：给定总数和页大小，返回页数与每页起止区间；页大小为零或负数时应拒绝。

## 查找与排序

9. **插入排序**：手动实现升序排序，不调用内置排序函数；验证空列表、重复值、负数和已排序输入。
10. **二分查找**：在升序列表中查找目标值；有重复值时返回第一个匹配位置，找不到返回约定的未命中值。
11. **合并有序列表**：将两个已排序列表合并为一个有序列表，保留重复元素；分析时间复杂度。
12. **Top N**：从记录列表中取金额最高的 N 条；金额相同时按订单号排序，并说明 N 为零、超过记录数时的结果。

## 自动化检查

每题至少准备正常输入、最小/最大边界、空输入、重复值和非法输入。可用 `pytest` 参数化这些例子；断言应检查完整结果，不只检查函数没有报错。
