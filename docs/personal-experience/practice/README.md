## Python 练习路线

本地 Python 题库目录覆盖数据类型、条件与循环、内置函数、字符串、排序和基础算法。按主题练习，再把边界检查和测试习惯加进去。

1. 基础类型、运算与类型转换
2. 字符串、列表、元组、字典和集合
3. 条件、循环、函数与常用内置函数
4. 排序、查找和简单算法
5. 用测试数据覆盖空值、重复值、边界和异常输入

## 测试设计练习

- **登录限制**：需求说“连续输错密码会暂时限制登录”。先列需要澄清的问题，再设计正常、边界、并发尝试、计时恢复和多端状态场景。
- **重复提交**：支付创建接口可能因超时重试。设计用例验证幂等键、重复请求、并发请求、不同请求体复用键和查询结果。
- **数据加载**：列表支持刷新和加载更多。覆盖空列表、最后一页、重复加载、刷新失败、网络中断恢复和排序一致性。
- **性能目标**：给核心查询定义目标响应分位值和成功率。写出负载模型、数据分布、观测指标、停止条件和报告结论边界。
