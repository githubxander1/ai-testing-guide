## 更新原则

- 记录可复现的步骤和验证结果；推测与已确认结论分开写。
- 练习仅使用公开或获准使用的系统，不提交账号密钥和真实业务数据。
- 每次实战尽量保留运行结果和问题定位依据。

## 上游同步

- `main` 跟踪原仓库 `upstream/main`，用于查看和接收原项目更新。
- 个人内容在 `my-practice` 分支的 `docs/my-practice/` 目录维护。
- 同步上游：`git switch main`，然后 `git pull --ff-only upstream main`；之后切回 `my-practice`，按需执行 `git merge main`。
- 个人分支推送到自己的 `origin`，原项目仍从 `upstream` 获取更新。
