# 接口自动化实战

## 练习目标

选公开靶场或本地部署系统，从关键业务流程开始，完成一套能重复运行、失败可定位的接口自动化项目。

## 实施顺序

1. 选定靶场，梳理接口、业务流程和可验证的结果。
2. 设计用例，覆盖正常、异常、边界及接口间关联。
3. 按需拆分用例、请求封装、断言、数据和报告，避免为分层而分层。
4. 实现登录态管理、参数化、公共请求、明确断言和清理策略。
5. 保存运行日志与报告，记录失败定位方法，并在 CI 中运行。
